# Healthy Valley Chiropractic Website

Professional GitHub Pages website for Healthy Valley Chiropractic.

## Live preview

https://jaimeespinalpr.github.io/healthy-valley-chiropractic-website/

## What is included

- Clean white design using the Healthy Valley Chiropractic logo colors.
- Hero section based on the current website structure.
- About, services, new patient special, testimonials, office hours and contact sections.
- Instagram video embeds in the testimonials section.
- Instagram and Facebook image cards.

## Local preview

Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
